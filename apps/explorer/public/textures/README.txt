Optional real Moon surface image
================================

The app works without any file here (it shows a labelled placeholder surface).

To show a real image instead, save this file in THIS folder with EXACTLY this name:

    moon_color_2k.jpg

Source (NASA Scientific Visualization Studio, CGI Moon Kit):
    https://svs.gsfc.nasa.gov/vis/a000000/a004700/a004720/lroc_color_2k.jpg
    Page: https://svs.gsfc.nasa.gov/4720

What it is: LRO Wide Angle Camera colour mosaic, 2048x1024, centred on longitude 0.
NASA's note: "optimized for aesthetics, not science".
Credit: NASA's Scientific Visualization Studio.

After saving it, refresh the page. The label at the bottom left of the Moon view will change
from "PLACEHOLDER SURFACE" to "NASA SVS CGI Moon Kit colour map".
