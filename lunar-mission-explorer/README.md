# Lunar Mission Explorer

Extract all files together and open index.html in a browser. No installation is required.

- style.css controls the theme and layout.
- app.js controls the mission selector, timeline and flight view.
- globe.js contains the globe renderer and sourced lunar coordinates.
- lunar-texture.js contains the NASA LRO mosaic from https://svs.gsfc.nasa.gov/4720/.
- spacecraft.js contains the illustrative 3D spacecraft models.
- catalog.js and history.js contain mission data.
